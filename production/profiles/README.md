# Profiles Directory

This directory is used for file-based configuration profiles.

## Purpose
Profiles allow you to define configuration templates or presets that can be applied to accounts or requests.

## File Format
- Files should be valid OpenRTB JSON files
- Profiles can contain default bid request structures or configuration settings

## Note
Please put only valid OpenRTB JSON files here. This directory is optional and may not be used in all Prebid Server configurations.
